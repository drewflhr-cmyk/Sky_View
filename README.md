This webpage focuses on select stars, constellations' and planets and displays them on a movable map.
No internet is required - the app does its own astronomical calculations.
The map and Moonrise/Moonset/ Sunset/Sunrise can all be adjusted for the user's current location.  The Jensen Beach stuff cannot.
Also Included is local tides, wind, and swell height for my location and Small Point, ME.  Using local buoys.
Each star is a clickable item with popup information boxes.
The next 2 Forida launches are displayed.
Space conditions are included.
